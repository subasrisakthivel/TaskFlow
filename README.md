# 🚀 TaskFlow
A Full Stack Task Management Application built using React.js, Node.js, Express.js, MongoDB, and JWT Authentication.

---

## ✨ Features

✅ User Authentication (JWT)
🔐 Secure Password Hashing (bcrypt)
➕ Add Task
✏️ Edit Task
🗑️ Delete Task
✔️ Mark Task as Completed
🔍 Search Tasks
📂 Filter Tasks (All / Completed / Pending)
📊 Dashboard Statistics
📈 Summary Page
⚠️ Form Validation
💾 MongoDB Database Integration
🌐 REST API Integration
📱 Responsive UI

---

## 🛠️ Tech Stack

Frontend
   React.js
   JavaScript (ES6+)
   Tailwind CSS
   React Router DOM
   Vite
Backend
   Node.js
   Express.js
Database
   MongoDB
   Mongoose
Authentication
   JWT (JSON Web Token)
   bcryptjs

---

## 🚀 Installation

Frontend
  npm install
  npm run dev
Backend
  npm install
  node index.js
